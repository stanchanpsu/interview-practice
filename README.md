# Interview Practice

Collection of coding problems and solutions for interview preparation.

## Philosophy

These problems are modelled after real-world interview problems I've encountered in recent interview rounds. Unlike standard LeetCode problems, these tend to be less about obscure or tricky DSA and more about practical, real-world scenarios that incorporate some DSA element like graph traversal or memoization. The problems also test language proficiency and real-world usage such as reading files, string parsing and cleaning, and handling messy data.
